L'Event

Donjon en Pagaille est un event communautaire où l'objectif est simple : tuer le plus de boss possible en équipe, dans tous les donjons de Fellowship.

Chaque boss tué compte pour le total communautaire. Plus la communauté joue, plus les paliers de récompenses se débloquent.

⚔️Tous les donjons Fellowship sont éligibles
📊Les kills sont comptabilisés via Fellowship Logs
👥Open à toute la communauté — inscriptions requises
🔄Synchronisation automatique toutes les 15 minutes

Participer
1
Activer les logs de combat
Télécharge l'application Archon et assure-toi que le paramètre Activate Combat Log est bien activé dans le jeu.
Guide complet : archon.gg — Getting started
2
Récupérer ton ID Fellowship
Rends-toi sur fellowshiplogs.com et cherche ton personnage. Ton ID est le nombre dans la barre d'URL.
Exemple — barre d'URL
fellowshiplogs.com/characters/151451/overview
👆 Le nombre en surbrillance, c'est ton ID. Note-le pour le formulaire.
Prêt à rejoindre la pagaille ?
Remplis le formulaire avec ton nom de personnage et ton ID Fellowship. Pouf t'ajoutera dès que possible.
